# 007. import のパス（`@/` の絶対パス）

- ステータス: 採用

## コンテキスト

import のパスの書き方を統一する。

## 決定

`@/`（`src/`）からの絶対パスで書く。同じフォルダ内のファイルだけ `./` の相対パスとする。

- ファイルを移動したときに、import の修正が小さく済む
- 同じフォルダには CSS Modules など本体に関連するファイルがあり、移動するときは一緒に移動するはずなので、相対パスでよい

## 検討した選択肢

- すべて相対パス: 階層が深いと `../../` が増え、移動時の修正も大きくなるため不採用
- 同じフォルダ内も絶対パス: 一緒に移動するファイルまでパスの修正が必要になるため不採用
