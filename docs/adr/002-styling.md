# 002. スタイリング（CSS Modules）

- ステータス: 採用

## コンテキスト

デザイン仕様で px 単位の余白やカラーコードが細かく指定されており、それを再現するスタイリング手法を決める。

## 決定

CSS Modules を採用する。

- スタイルを tsx から別ファイルに分離でき、見やすく修正しやすい
- 指定値をそのまま CSS に書けばよく、ユーティリティクラスを用意したライブラリは不要

## 検討した選択肢

- CSS-in-JS（styled-components など）: スタイルが tsx 内に混在し、見通しが悪くなるため不採用
- Tailwind CSS: デザインの指定値が細かく、用意されたクラスの恩恵が小さいため不採用
