# 012. レスポンシブ対応（2 パターン、ドロワー）

- ステータス: 採用

## コンテキスト

レスポンシブ対応は加点要素。デザインに SP 版はないため、レイアウトを決める。

## 決定

- 1024px 未満（SP・タブレット縦画面）と、それ以上（PC）の 2 パターンとする
  - iPad の縦画面（768〜834px）では、PC 用のレイアウトだと本文の幅が約 300px しか残らないため
- 1024px 未満では、サイドバーをドロワーにする
  - ヘッダーのメニューボタンで開き、ページを移動すると閉じる
  - 余白を 16px 程度に縮める。Edit などのボタンは右側の列のまま

## 検討した選択肢

- 3 パターン以上（SP・タブレット・PC）: 3パターンにする必要性が無さそうだったため不採用
- 切り替え幅を 768px: タブレットの縦画面で本文が狭くなるため不採用
