# 008. export と関数の書き方

- ステータス: 採用

## コンテキスト

コンポーネントやそれ以外の関数の export と書き方を統一する。

## 決定

- React コンポーネントは `export default function` とする（決めの問題だが、統一するため）
- hooks・関数・定数などは named export とし、関数はアロー関数で書く
  - 見やすさのため
  - コンポーネント（`export default function`）と見分けやすくするため

## 検討した選択肢

- コンポーネントも named export: どちらでもよいが、コンポーネントとそれ以外を見分けやすくするため不採用
- 関数をすべて `function` 宣言: コンポーネントとの区別がつきにくいため不採用
