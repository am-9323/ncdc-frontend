# 018. 複数クラスの指定（clsx）

- ステータス: 採用

## コンテキスト

CSS Modules（002）で複数のクラスや条件付きのクラスを指定する書き方を決める。テンプレートリテラル、三項演算子＋空文字、`filter(Boolean).join(' ')` など、箇所ごとに書き方がばらついていた。

## 決定

`clsx` を使い、複数のクラスを指定する箇所はすべて `clsx(...)` で書く。

- 条件付きのクラスはオブジェクト形式（`{ [styles.active]: isActive }`）で書く
- 書き方が揃い、余分な空白や `false` が混ざる心配がない
- 依存なし・軽量（約 240B）で、広く使われている

## 検討した選択肢

- テンプレートリテラル / `filter(Boolean).join(' ')`: 条件が増えると読みにくく、書き方もばらつくため不採用
- 自前のユーティリティ関数: `clsx` と同等のものを作る意味が薄いため不採用
- `classnames`: 機能は同等だが `clsx` のほうが小さく速いため不採用
