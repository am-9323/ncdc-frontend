# 011. バリデーション（自前の関数）

- ステータス: 採用

## コンテキスト

タイトル（1〜50 文字）と本文（10〜2000 文字）の文字数を検証する。検証の方法を決める。

## 決定

ライブラリを使わず、`src/features/content/utils/validate-content-field.ts` の自前の関数で検証する。

- 検証するのは 2 項目の文字数だけで、フォームライブラリも使っていない
- 絵文字を 1 文字と数えるなど、数え方を自由に決められる

## 検討した選択肢

- Zod: 今回の範囲では過剰。`.min()` / `.max()` は `string.length` で数えるため、数え方を変えるには `refine` が必要で手間が変わらないため不採用
