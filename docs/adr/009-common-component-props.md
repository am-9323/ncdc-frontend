# 009. 共通コンポーネントの props

- ステータス: 採用

## コンテキスト

`Button` などの共通コンポーネントで、HTML 要素の属性をどこまで受け取るかを決める。

## 決定

必要な props（`disabled`、`onClick` など）だけを受け取り、属性を絞る。

- 呼び出し側から `className` や `style` でスタイルを変えられないようにし、デザインを崩せないようにする

## 検討した選択肢

- `ComponentPropsWithoutRef<'button'>` で元の要素の属性をすべて引き継ぐ: 柔軟だが、見た目を崩せてしまうため不採用
