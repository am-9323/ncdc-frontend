# 004. データ取得（TanStack Query + fetch）

- ステータス: 採用

## コンテキスト

ページの一覧（サイドバー）と詳細を API から取得し、作成・更新・削除の結果を両方に反映する必要がある。

## 決定

サーバー状態の管理に TanStack Query、HTTP クライアントに fetchを使う。

- 状態管理を行いやすく、シンプルに記述できる

## 検討した選択肢

- useEffect + useState: 読み込み中・エラー・再取得を自前で書く必要があり記述が増えるため不採用
- axios: 本課題の API 数では fetch で十分なため不採用
